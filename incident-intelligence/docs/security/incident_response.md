# Security incident response

1. Record detection time, reporter, affected deployment, and evidence without modifying originals.
2. Contain access by disabling accounts, incrementing token versions, rotating environment secrets, and restricting network paths.
3. Preserve audit, API, database, host, and reverse-proxy logs.
4. Assess customer evidence exposure and operational-system credential scope.
5. Notify the designated customer contact according to contract and applicable law.
6. Eradicate the cause, restore from verified backups if needed, and validate health and artifact hashes.
7. Document root cause, corrective actions, and follow-up verification.
