# Secure transfer options

Use a customer-approved expiring upload portal, encrypted managed file share, customer-hosted SFTP, or encrypted removable/offline transfer. Prefer customer-managed access, named recipients, expiry, MFA, and download audit. If using archive encryption, exchange the key through a separate approved channel.

Email attachments and public links are not accepted for operational evidence. Record sender, recipient, time, archive/file hash, expiry, encryption method, and deletion date. Verify the SHA-256 fingerprint after receipt before analysis.
