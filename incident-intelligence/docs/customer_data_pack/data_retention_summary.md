# Data retention summary

Retention is engagement-specific and must be agreed before transfer. The application supports preview, independently approved deletion execution, and deletion receipts. Backups and external log stores must use compatible expiry rules.

Recommended pilot record: purpose; data categories; owner; start date; retention end; legal/contract basis supplied by the customer; report retention; raw-evidence retention; backup expiry; vendor-sharing restrictions; approver; and deletion receipt. See `docs/security/data_retention.md`. This summary is operational guidance, not legal advice.
