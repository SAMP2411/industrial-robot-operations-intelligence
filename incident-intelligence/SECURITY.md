# Security policy

Please report suspected vulnerabilities privately to the repository owner or designated security contact. Do not open a public issue containing credentials, customer evidence, exploit details, or personal data.

Include the affected version, deployment mode, reproduction steps, likely impact, and any temporary mitigation. Acknowledge, triage, remediation, and disclosure targets are documented in [vulnerability management](docs/security/vulnerability_management.md).

This repository is validation-ready software, not a certified safety component. It must never be connected with credentials that allow robot, PLC, WMS/WCS, fleet, door, lift, charger, or safety-system writes.
